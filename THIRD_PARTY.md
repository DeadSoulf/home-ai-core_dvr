# Third-party components

## Hikvision HCNetSDK

This repository contains Linux amd64 runtime binary components originating from Hikvision HCNetSDK V6.1.9.48, supplied by the project owner for use in this DVR project.

These files are not claimed to be open-source. Their use and redistribution are subject to the applicable Hikvision terms and license.

## hls.js

The web UI contains a bundled `web/vendor/hls.min.js` dependency used for browser HLS playback.
