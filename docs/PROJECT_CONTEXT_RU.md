# Контекст проекта HOME AI Core / NVR

## 1. Общий принцип проекта HOME AI Core

HOME AI Core строится как модульная система.

Главное правило архитектуры:

**Ядро HOME AI Core не должно содержать внутри себя функциональные модули.**

Отдельные функции должны устанавливаться как независимые Docker-контейнеры:

- NVR;
- AI;
- камеры;
- другие будущие модули.

Модули должны скачиваться, обновляться и удаляться отдельно от ядра.

Из Core ранее было решено удалить старые встроенные наработки AI/NVR и постепенно переносить функциональность в отдельные контейнеры.

Он умел:

# 6. Локальная запись

NVR теперь умеет самостоятельно постоянно записывать видеопотоки.

Запись выполняется через FFmpeg.

Для Hikvision схема:

`HCNetSDK -> sdk-stream -> FFmpeg -> локальный архив`

Для RTSP:

`RTSP -> FFmpeg -> локальный архив`

По возможности используется копирование исходного кодека без перекодирования, чтобы уменьшить нагрузку CPU.

---

# 7. Архив

Основной каталог данных контейнера:

`/app/output`

Локальные записи:

`/app/output/recordings`

Логи recorder:

`/app/output/logs`

`/app/output/nvr.db`

`./data/output:/app/output`

Поэтому архив и база переживают пересоздание контейнера.

---

# 8. SQLite

Используется встроенный Python SQLite.

Основные таблицы:

- `cameras`
- `recordings`

В базе сохраняются:

- камеры;
- параметры подключения;
- состояние камеры;
- индекс записей;
- время начала/окончания записи;
- размер файла;
- путь к записи.

После рестарта контейнера включённые камеры должны автоматически снова запускаться на запись.

---

# 9. Сегментация записи

Текущий параметр:

`NVR_SEGMENT_SECONDS=300`

То есть один файл записи примерно:

**5 минут**

После завершения сегмента файл индексируется в SQLite.

Поэтому сразу после включения камеры поле `recordings` может какое-то время оставаться `0`.

---

# 10. Retention / хранение архива

Сейчас по умолчанию:

`NVR_RETENTION_DAYS=7`

Хранить до:

**7 дней**

Также:

`NVR_MAX_STORAGE_GB=50`

Максимальный объём локального архива:

**50 ГБ**

Если объём превышает лимит, самые старые записи удаляются.

Важно:

в русской локали PowerShell:

`50,0`

означает обычное число:

`50.0 GB`

Можно позже заменить фиксированный лимит на использование физического диска и резерв свободного пространства.

---

# 11. Поддержка камер

Добавлена поддержка:

**до 32 камер**

Переменная:

`NVR_MAX_CAMERAS=32`

API показывает:

- `cameras`
- `max_cameras`
- `camera_slots_free`

При попытке добавить 33-ю камеру API должен вернуть ошибку.

Это программный предел текущей версии.

Перед реальным использованием 32 камер необходимо провести нагрузочное тестирование дисковой подсистемы, сети и CPU.

# 25. Наш принцип работы

При дальнейшей работе придерживаться следующего порядка.

Пользователь хочет, чтобы ChatGPT не просто давал инструкции, а **сам выполнял работу**, если соответствующий доступ доступен.

Если есть доступ к:

- GitHub — самостоятельно изменять репозиторий;
- компьютеру/терминалу — самостоятельно запускать команды;
- Docker — самостоятельно пересобирать и проверять контейнер;
- файлам — самостоятельно редактировать их.

Не нужно каждый раз спрашивать подтверждение для обычных технических изменений, если задача уже поставлена однозначно.

После изменений:

1. внести изменения;
2. проверить;
3. сообщить, что сделано;
4. дать пользователю только то действие, которое невозможно выполнить самостоятельно.

Не надо снова спрашивать уже известные данные.
