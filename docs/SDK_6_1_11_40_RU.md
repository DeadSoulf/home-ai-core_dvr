Изучен исходный архив Hikvision `EN-HCNetSDKV6.1.11.40_build20260922_linux64.zip`:
SHA-256 `2b8be43fd1cf0d4bd16d4a3b5860c214ee278fd851ea0c59ab0e0b4a9eceee29`.
В него входят `libhcnetsdk.so`, полный `HCNetSDKCom`, зависимости OpenSSL 3,

## Безопасный способ сборки

В основной публичный образ и репозиторий **не добавляются** библиотеки из
переданного архива. Для создания нового образа локально используйте официальный
архив, находящийся **вне** исходного Git-репозитория:

```bash
sh tools/build_sdk611_local.sh /secure/vendor/EN-HCNetSDKV6.1.11.40_build20260922_linux64.zip
```

Скрипт проверяет SHA-256, выборочно извлекает необходимые библиотеки без
распаковки опасных путей, проверяет бинарную архитектуру/ABI и использует
Docker BuildKit с изолированным контекстом `vendor_sdk`.
Образ: `home-ai-core-nvr:1.1.6-sdk611-local`, Linux amd64.

## Поддерживаемые нативные операции

- Проверка SDK при запуске (V40, строгая версия 6.1.11.40);
- Авторизация Hikvision и вывод доступных аналоговых и IP-каналов;
- Непрерывный PS-видеопоток через V40 callback → FFmpeg → NVR;
- Снимки JPEG;
- PTZ направления, zoom/focus/iris с ограниченной скоростью и временем;
- Пресеты «установить» и «перейти».

При локальном запуске сохраняйте постоянный каталог `/data` на назначенном
физическом диске, не форматируйте раздел и не удаляйте `nvr.db` или записи.

В локальном SDK611-образе отключены прежние ограничения 50 ГиБ и
7 дней (`NVR_MAX_STORAGE_GB=0`, `NVR_RETENTION_DAYS=0`).
Резерв `NVR_MIN_FREE_GB=20` оставляет 20 ГиБ свободного места на
выделенном диске: при заполнении **автоматически удаляются старые
завершённые** записи. При необходимости бессрочно хранить весь архив
отключите резерв, задав `NVR_MIN_FREE_GB=0`, и самостоятельно следите
за свободным местом. Перед удалением старых записей создайте резервную копию.
Обязательно проверьте назначенный диск по UUID средствами Core — сам
локальный Dockerfile не определяет физический диск.

**Пока не включены:** `sdk-extended` (device status, voice, archive search/
download) и `sdk-alarm-monitor` — нет исходников старых утилит, а их ABI
относится к предыдущей версии SDK. Вместо смешивания OpenSSL 1.1/3 эти
операции явно возвращают код 78. Live View, штатная запись NVR и локальный
архив остаются доступными; нельзя выдавать неподдерживаемую функцию за
успешно выполненную.

Не публикуйте образ с проприетарными компонентами без проверки лицензии
Hikvision. Реальные сетевые устройства, операции PTZ, снимки, стабильность
видеопотока, перезагрузка и восстановление архивов требуют отдельного теста
на целевом сервере. **Скрипт не устанавливает образ в работающий Core.**
